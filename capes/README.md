# Картинки плащей

Каждый плащ лежит в двух видах:
- `<имя>.png` — картинка 92×144 (смотреть/править);
- `<имя>.hex` — те же пиксели для скрипта (`W,H;` + hex RGB построчно).

Скрипт качает `.hex`, режет на 9 полос (по 16 строк) и кэширует в `WannacryAssets/img_r1_<имя>_<n>.png`.
Чтобы заменить картинку: обнови оба файла и подними `Tex.IMG_REV` в скрипте (иначе останется кэш).
