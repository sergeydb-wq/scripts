# wannacry hub — запуск на Wispbyte

1. Создай сервер на Wispbyte с типом **Node.js**.
2. Загрузи в файлы сервера `index.js`, `package.json`, `config.json`.
3. В `config.json`:
   - `hubKey` — придумай любой ключ (например `wc_8fK2mQx9Lp`);
   - `admins` — токены для Tobby2281E и sergeoomg, **минимум 12 символов**, у каждого свой.
4. Стартовый файл — `index.js` (обычно уже стоит по умолчанию). Нажми **Start**.
   В консоли должно появиться: `[hub] wannacry hub слушает порт ...`.
5. Скопируй адрес сервера (IP:порт) из панели Wispbyte.
6. В начале `wannacry.lua` в `WC_NET` впиши:
   - `hubUrl = "http://IP:ПОРТ"`
   - `hubKey` — тот же, что в `config.json`.
7. Каждый админ один раз выполняет в экзекьюторе:
   `writefile("chat_token.txt", "СВОЙ_ТОКЕН")`
   (тот же файл, что использует твой admin_chat лоадер — если токены совпадают, делать ничего не нужно).

Проверка: открой в браузере `http://IP:ПОРТ/health` — должно вернуть `{"ok":true,...}`.

Админ-чат хранится в `adminchat.json` рядом с сервером (последние 300 сообщений).
